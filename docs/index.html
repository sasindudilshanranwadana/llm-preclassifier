llm-preclassifier OFFLINE-FIRST

Agent request preflight / v0.1

Classify the task before the expensive call.

A self-hosted decision service for agent workflows. Inspect task shape, complexity, and likely tool need before your application chooses a model or invokes a tool.

VIEW SOURCE ↗TRY THE DEMO ↓

Apache-2.0. Runs offline by default. It recommends a configurable tier; it does not select a provider or execute a request.

POST /v1/classify
{
  "task_type": "coding",
  "complexity": "complex",
  "tool_requirement": "required",
  "recommended_model_tier": "capable",
  "confidence": 0.88,
  "action": "route",
  "reasons": [
    "tool_required",
    "multi_step_or_artifact_signal"
  ]
}
// no provider key required

Design constraints

A sidecar, not another gateway.

[ 01 ]

Offline baseline

Deterministic rules make a useful decision without forwarding prompts to a vendor or requiring a paid model.

[ 02 ]

Inspect the why

Every response carries versioned labels, confidence, action, and reason codes. Your policy remains yours.

[ 03 ]

Abstain safely

Ambiguous or high-stakes signals can return unknown or escalate; this service does not certify safety.

Composition model

Keep routing policy out of the black box.

01 / REQUESTPass OpenAI-style messages plus optional available-tool metadata.
02 / CLASSIFYOffline rules label task shape and identify explicit signals.
03 / DECIDEReceive a versioned tier recommendation and an action.
04 / ACTYour agent, LiteLLM policy, or custom loop chooses what happens next.

Minimal integration

A local decision in one request.

docker compose up --build
